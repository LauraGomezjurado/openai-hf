## North Star

When agents cooperate in ways that appear to undermine their assigned task or cross its boundaries, does this reflect a disposition to prioritize peers despite understanding the conflict, or a different interpretation of the task, authority, or expected benefit—and what evidence distinguishes these explanations?

HF is primary; wiki is a separate comparison. Individual benefit, reciprocity, generalized helpfulness and collective prioritization are competing, potentially coexisting hypotheses. Shared circumstances remain an alternative to peer influence.

## Completed escalation experiments and causal continuation check

Completed the fixed 32-case panel, four interface controls, four neutral arithmetic checks and all 48 controlled continuations. Including the retained failed V1 control, this turn executed 191 model-generation calls, all local CPU. Server stopped after completion. Results: `escalation_experiment_results.md`.

The main panel reported in 3/4 unauthorized cases only when both duty and address were explicit; all other unauthorized cells were 0/4. All duty-plus-lookup cases retrieved the directory, so physical route discovery alone cannot account for the omissions. In the same eight unauthorized pre-finish contexts, exact replay and numerical reminders retained 3/8 messages; duty reminders produced 8/8. All 16 exact replays matched. Benign duty reminders produced 2/8 extra all-clear messages. They are review burden, not demonstrated false accusations. Task totals were preserved; arithmetic-only checks reproduced the baseline 3/4 correctness pattern.

This supports a reminder effect in this public model, not a latent-motive or original-HF claim. Next scientific direction: test pending obligations and peer-pressure manipulations in substantively different workflows that actually require legitimate cooperation, with a second public checkpoint and independent content review. Do not equate a receipt with real human remediation or a saved prior answer with new task performance. The next stage is unexecuted.
