# Recording examples alongside empirical claims

For new experiments and analyses, retain key examples together with full outcome counts and provenance. An example illustrates a finding; it cannot by itself establish prevalence, causation or a latent motive.

Each example record should contain: claim and bounded interpretation; evidence type; study/model/condition/case ID; exact source path and line or structured pointer; source checksum; relevant step numbers; short excerpt or recorded action; aggregate result it illustrates; missing evidence and alternative interpretations. Preserve failures and contrary examples as well as successful interventions. State the selection rule. Keep the full surrounding context reachable.

Distinguish authentic published reasoning excerpts from investigator paraphrases, analyst interpretations, outbound messages and tool actions. Do not fabricate missing chain of thought or present a narrative paraphrase as a verbatim trace. Separate the HF incident, the historical wiki comparison, public benchmark records, new model experiments and synthetic method fixtures.

For statistical claims, link the aggregate calculation and input manifest as well as a concrete illustrative row. For a null result or absence claim, examples are insufficient: retain the full denominator, missingness and measurement rules. If no suitable example exists, record that gap explicitly.

Current new-study selection rule: lexicographically first case/pair within each declared outcome class and model. The gallery includes success, omission, work failure, benign notifications, intervention gains/losses and peer-pressure gains/losses where available. This is a reproducible illustrative selection, not a representative subsample. Human semantic labels remain distinct from mechanical scores and assistant provisional interpretations.
