# What the historical data makes possible

September 6, 2026. These are proposed contributions and decision gates, not established novelty claims. HF remains primary; the wiki archive is a separate comparison.

## 1. HF measurement and identifiability study — pursue now

Question: which conclusions about participation timing survive plausible timestamp, censoring, and event-definition uncertainty?

The public figure assets make this possible without recreating the attack. We already have reproducible ordering audits, follow-up ranges, and timing perturbations. The July 9/11 contrast survives the tested ±5-minute endpoint scenario but loses separation under ±30 minutes. This identifies the timing precision needed to defend the contrast; it does not estimate actual error or establish peer influence.

Next experiment: after obtaining event-level timing grades, replace uniform perturbations with grade-specific feasible intervals and retain dependence between timestamps reconstructed from shared anchors. Report which orderings and cohort contrasts hold across all feasible assignments. If grades remain unavailable, publish the assumption-dependent result and unresolved fields explicitly. A methods note/data companion is supportable now; a causal recruitment claim is not.

## 2. Linked evaluator-belief and strategy episodes — highest-value HF access target

Question: when a participant explicitly revises a belief about scoring or scope, is a subsequent strategy change visible, and what alternatives explain it?

The selected HF passages justify a focused codebook, but cannot establish incidence or effects. A useful pilot release would include linked message, recipient-read evidence, and subsequent action records for both apparent adoption and non-adoption. Selection must be documented; controls should include ordinary work, unsuccessful persuasion, and similar task/access changes without the focal message.

Next experiment: two independent reviewers annotate temporal order, stated belief, action evidence, and competing explanations. Proceed to a descriptive episode study only if the links and categories are reliable. Progress to an observational effect estimate only if the exposure process, population and confounders are sufficiently observed. A persuasive quotation is not that gate.

## 3. Correction and corroboration tracing — separate wiki comparison

Question: can we distinguish copied agreement, claimed replication, and a correction followed by a changed answer using original revision histories?

The archive supports before/after text and some chronology. Our first link review exposed a concrete failure mode: a page link and replication phrase can concern different propositions. That makes proposition-level validation more valuable than a larger keyword sweep.

Next experiment: use the prepared linked packets to develop labels, then sample new episodes from correction candidates and matched ordinary replies with documented selection probabilities. Trace the specific disputed proposition through earlier history. Group shared posts, page families and copied passages before any split. Report claims of replication separately from execution evidence. Stop short of causal diffusion or distinct-agent counts when reads and identities are unavailable.

## 4. Historical-input monitor evaluation — defer until labels exist

Question: does exposing a monitor to earlier peer context improve detection of a labeled historical behavior over the focal passage alone?

Compare focal passage, passage plus prior context, and an irrelevant-context control on untouched episode groups. Use human labels, record abstentions, and assess false positives on ordinary collaboration. This tests a new monitor on historical evidence; it does not identify the original agents' internal mechanism. The present three-row provisional holdout is inadequate. Only after an adequately sized independent set exists should we select a model and consider one free GPU.

## What to stop doing for now

The chronological forecasts failed simple baselines, and the workstream input was retrospectively selected. More feature searches would add little evidential value. Simulation, RL reproduction and internal circuit analysis do not answer the user's historical-data question with the records currently available.

The useful change in scope is that we can now formulate falsifiable measurement and episode questions around real records. The next scientific bottleneck is provenance and independent interpretation, not compute. Outreach is drafted but unsent; no cluster job or background process is running.
