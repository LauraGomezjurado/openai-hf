# CPU analysis plan, frozen before expanded outcome analysis

Date: September 6, 2026. The initial recruitment plot and its July 9/11 counts were already inspected. This is a prospective specification for the next exploratory analyses, not a preregistration independent of all outcomes.

1. Validate all timeline orderings, missingness by family/day, rounding, plot-window endings, and featured-row selection. Preserve violations.
2. Use first-read cohorts and 1/6/24-hour horizons. Report follow-up availability ranges, not confidence intervals. Stress-test independent per-timestamp error of ±5/30/120 minutes (differences can move by twice that amount). Retain the nominal cohort/risk denominator and disclose midnight and pre-read ambiguity. Repeat excluding featured rows and within family. Quantify sensitivity to unknown false-negative onset labels separately from early follow-up endings.
3. Plot cumulative observed-onset/follow-up ranges. Do not present Kaplan–Meier as ground truth: run ending, censoring, and classification failure cannot be separated here.
4. Fit hourly landmark onset predictions only as an exploratory retrospective diagnostic. Baseline: calendar time, daily cycle, run age, model family. Add board tenure. Train only on intervals resolved before the forecast boundary; score contiguous 12-hour blocks after at least 24 hours of training. Ridge penalty fixed at 1 on standardized covariates. Also evaluate rows not previously seen in training, so an apparently successful within-run forecast is not confused with new-agent generalization. Report Brier/log loss and per-block results; no independent-agent significance tests.
5. Join hourly workstream counts to onset counts by UTC for a **provisional ecological analysis**. Population comparability remains unconfirmed. Use Poisson ridge regression (fixed penalty 1), baseline previous-bin onsets, previous-bin total traffic, calendar/daily-cycle terms; augment with previous-bin HF-results share and assignments share. Expanding forecasts after 48 hours, refit every 12 hours. Compare persistence and training-mean baselines. Repeat at 1/2/6-hour bins, with automated/file traffic excluded, and outcome timestamps shifted ±1/±2 hours. No causal/operational claims. A time-reversed or block-shift association is a diagnostic, not a randomization test.
6. Extract wiki revision deltas without executing content. Preserve unknown baselines and distinguish repeated text from additions. Produce a deterministic 50-episode page-grouped annotation sample plus a separately marked purposive sample for corrections, uptake and evaluator beliefs. Lexical matches are retrieval aids, not truth labels. Holdout assignment by page-connected component, not revision. Do not train/evaluate a monitor without independent labels.
7. Build an HF claim/episode ledger from publication annotations and report sections, preserving quote/paraphrase/interpretation categories. Do not infer missing actions or hidden mental states.
8. Update the research protocol and a current-status memo with completed work, failed hypotheses, data limitations, and highest-value next actions. No researcher outreach or cluster use is authorized by this analysis plan.

Stopping rule: finish these local analyses and their meaningful integrity checks. Stop expanding numerical models when the data cannot identify the requested quantity or a benchmark lacks labels; document the limitation instead of searching for a favorable model. Additional CPU work can always be invented, so “local work exhausted” will mean this decision-relevant work package is complete, not a claim that every possible computation has been performed.
